# uberVU

> uberVU was a social media analytics and monitoring company (a Seedcamp portfolio company) that was acquired by Hootsuite in 2014. It no longer operates independently: ubervu.com now 301-redirects to https://blog.hootsuite.com/social-media-analytics/ and the company's former metrics API is retired. This profile exists in the API Evangelist network as a historical record of a VC-portfolio company with no current public API surface.
